# 📝 Node.js Blog Post Application

A simple and secure Blog Post API built with **Node.js**, **Express.js**, and **MongoDB**. This application allows users to create, read, update, and delete blog posts. It also features user authentication and authorization using **JWT** and password hashing with **bcrypt**.

## 🚀 Features

- User Authentication (Register & Login)
- JWT-based Authorization
- Create, Read, Update, Delete (CRUD) blog posts
- Secure password hashing using bcrypt
- MongoDB/Mongoose schema models for Users and Posts
- RESTful API design

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB + Mongoose
- **Authentication**: JWT (JSON Web Token)
- **Password Security**: bcrypt
- **Environment Variables**: dotenv
